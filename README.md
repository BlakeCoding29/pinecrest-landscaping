# Pinecrest Landscaping

A fictional landscaping-company website built as a portfolio demo.

## Live Demo

https://blakecoding29.github.io/pinecrest-landscaping/

## About This Project

Pinecrest Landscaping is a responsive, single-page website for a fictional landscaping company based in Kalispell, Montana.

It includes:

- A polished hero section and service overview
- A featured mountain-home fire-pit project
- Responsive styling for phones and desktops
- Calls to action for estimates and contact

## Built With

- HTML
- CSS
- Git and GitHub

> This is a fictional business created for portfolio purposes.
